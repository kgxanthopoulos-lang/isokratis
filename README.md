# Ισοκράτης

Ισοκράτημα βυζαντινής μουσικής στο κινητό: 8 ήχοι με τα διαστήματα της Πατριαρχικής Επιτροπής (72 μόρια), ηχογραφημένες φωνές χορωδίας, αυτόματη εύρεση βάσης και «έξυπνο ίσον» που ακούει τον ψάλτη.

Άνοιγμα: https://kgxanthopoulos-lang.github.io/isokratis/

Φωνές: FluidR3 GM (Frank Wen, MIT), MusyngKite (Gary Hagan Cole, CC BY-SA 3.0) και FatBoy, μέσω midi-js-soundfonts (Benjamin Gleitzman).
